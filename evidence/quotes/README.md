# Redacted official quote evidence

Place redacted copies of official quote results here when available. For each quote, retain enough non-identifying evidence to reproduce the amount:

- insurer, product/version and quote date/time
- prenatal/postnatal stage, premium payment term and maturity
- input assumptions, rider names and coverage amounts
- premium breakdown and total
- SHA-256 hash of the redacted evidence file

Remove names, resident registration numbers, phone numbers, addresses, authentication information, quote/session tokens, and any other unnecessary identifying details. Do not store passwords or one-time authentication codes.

The repository's current premiums are unverified legacy values. Do not relabel them as actual quotes until this evidence has been independently checked.
