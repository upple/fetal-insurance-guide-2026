# Row-level evidence for the legacy N=350 dataset

Store privacy-redacted screenshots/PDFs or archived copies of source posts here only when rights and access permit. Record the matching row in ../market_sample_provenance_template.csv with source URL, archived URL/post ID, post and capture dates, evidence filename and SHA-256, data type, and duplicate cluster.

Do not include names, handles, profile photos, resident registration numbers, phone numbers, addresses, policy numbers, quote/session tokens, or other unnecessary identifiers. Keep only the evidence needed to assess source authenticity and the quoted product/premium terms.

The existing 350 rows have not been independently verified. Adding a file does not verify a row until the source, premium, product conditions, and duplicate status have been reviewed.
