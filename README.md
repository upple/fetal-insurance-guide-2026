## 🎯 핵심 3대 가입 원칙

1. **최적의 조합:**  
   **현대해상 굿앤굿어린이종합보험Q (20년납 30세 만기, 계약전환제도 탑재) + 5세대 태아 실손의료비**
2. **합리적인 월 보험료 구조:**  
   - 출생 전: **월 약 42,000원**
   - 출생 1년차(0세): **월 약 61,000원** (실손 27,000원 최고점 구간)
   - 출생 2년차 이후: **월 4~5만 원대 안착** (실손보험료 1만 원대로 자동 하락)
3. **가입 골든타임:**  
   **임신 10~12주 (1차 기형아 검사 전)** 완료 필수 (마지노선 22주 6일)
