# 2026 태아보험 검토 가이드

> 현대해상 굿앤굿어린이종합보험Q(Hi2607)를 중심으로, 태아보험 설계안을 읽고 비교하는 방법을 정리한 검토 문서입니다.

## 먼저 읽을 결론

이 저장소의 표준안은 **29세 사무직·무병력·단태아를 가정한 20년납 30세 만기 예시**입니다. 출생 전 약 4.3만 원, 출생 직후 약 6.2만 원이라는 숫자는 해당 입력값에서 나온 견적 예시이지, 모든 가입자에게 적용되는 확정 보험료가 아닙니다.

판단 순서는 다음이 가장 안전합니다.

1. **표준 설계안**에서 보장 우선순위와 입력 프로필을 확인합니다.
2. **특약 매트릭스**에서 실제 가입금액·지급 조건·가입 가능 주수를 대조합니다.
3. 병력이나 이상소견이 있으면 **인수심사 시나리오**를 참고하되, 보험사의 사전심사를 별도로 받습니다.
4. 보험료와 계약전환은 이번 검토에서 대조한 **공식 상품 페이지·약관·청약 화면의 조건**을 기준으로 읽고, 개인 청약에서 달라지는 값만 별도로 반영합니다.

### 이 문서가 말하는 것

- 실손의료비, 정액 진단비, 후유장해, 신생아·선천이상 담보의 역할을 나누어 중복을 줄이는 방법
- 30세 만기와 100세 만기를 비교할 때 확인해야 할 보험료·보장기간·계약전환 조건
- 공개된 공식 자료와 내부 관찰 표본을 구분해 견적을 읽는 방법

### 이 문서가 말하지 않는 것

- 특정 상품이나 설계가 모든 가정에 최선이라는 결론
- 산모의 병력, 검사 결과, 직업, 태아 성별을 반영하지 않은 확정 가입 가능 여부
- 갱신보험료나 출생 후 보험료가 반드시 내려간다는 보장
- 계약전환 대상이 아닌 담보까지 자동으로 80·90·100세로 연장된다는 의미

## 판단 기준

### 1. 담보는 역할별로 확인합니다

- **실손의료비:** 실제 부담한 의료비를 약관 범위에서 보전합니다.
- **진단비:** 질병 진단 시 정액으로 지급되어 치료 외 소득 공백에 대응합니다.
- **후유장해:** 장해율과 약관상 지급 기준에 따라 지급됩니다.
- **태아·신생아 담보:** 출생 직후 입원, 저체중, 선천이상 등 특정 조건을 충족할 때 지급됩니다.

“필수”라는 표현은 가족의 예산과 위험 선호를 반영한 편집상 분류입니다. 실제 지급 여부는 특약명, 가입금액, 면책·감액·지급 조건을 기준으로 판단해야 합니다.

### 2. 가입 시점은 경험칙과 약관을 구분합니다

10~12주 이전 가입은 실무상 조기 준비 시점일 수 있지만 법정 마감일은 아닙니다. 12주 또는 22주 6일 제한은 상품과 특약별로 다르므로, 가입 화면과 상품설명서에서 담보별 조건을 확인해야 합니다.

### 3. 30세 만기 계약전환은 제한된 안전장치입니다

현대해상 공식 안내([S1](SOURCE_MANIFEST.md))에는 계약전환 대상 담보에 대해 최대 100세 전환이 안내되어 있습니다. 이는 모든 담보가 자동 연장되거나 모든 건강 이력을 무심사로 처리한다는 뜻이 아니며, 전환 가능 담보·전환 시점·보험료 산정 조건을 특별약관에서 확인해야 합니다.
